#Installation of Nmap

During the installation of Kali Linux, there was an option for installing all defaults network test applications but we also can install Nmap by our own ways. The steps of this are:

-open the terminal by press Ctrl+Alt+T or choose directly in the applications library
-type the command "sudo apt install nmap", enter the password of the user and follow the intructions(for our case a choice of Y/n was be presented and we selected the Y option)

#Nmap description
Nmap is a open source tool for network scanning used by systems administrators, network engineers and cybersecurity professionals.
It is mainly used for discover devices connected to a network, identify open ports on a computer or server, detect services running on those ports, identify the operating system and audit the security of a network.

#Necessity of a network scanning
Network scanning is essential because it allows to identify devices connected to a network, discover open ports, detect running services and undercover potential vulnerabilities. It helps improve secuirty, monitor network infrastructure and troubleshoot connectivity issues.

#Ethical use guidlines
-Obtain permission before scanning a network or system
-Use scans only for legitimate administration, maintenance or security purposes
-Respect privacy and the confidentiality of discovered data
-Comply with applicable laws, regulations and organizational policies
-Document findings responsibly and report vulnerabilities to authorized individuals

#Installation of Nmap

During the installation of Kali Linux, there was an option for installing all defaults network test applications but we also can install Nmap by our own ways. The steps of this are:

-open the terminal by press Ctrl+Alt+T or choose directly in the applications library
-type the command "sudo apt install nmap", enter the password of the user and follow the intructions(for our case a choice of Y/n was be presented and we selected the Y option)
